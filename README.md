# pos-pwa

PWA de Punto de Venta (POS) **offline-first**, adaptable a distintos nichos.

## Arquitectura y Documentación
- `AGENTS.md` — Reglas de desarrollo e instrucciones para agentes de IA.
- `docs/PLAN_DE_TRABAJO.md` — Cronograma y ritmo de trabajo semanal.
- `docs/SPEC.md` — Especificación de producto, arquitectura, modelo de datos y reglas de negocio.
- `docs/API_CONTRACT.md` — Contrato de API entre la PWA y el backend (sincronización y autenticación).
- `docs/BACKLOG.md` — Detalle de sprints (S0 a S11), tareas y criterios de aceptación.

## Requisitos
- Node.js (v20+ LTS o superior)
- pnpm (v9+)
- Git
